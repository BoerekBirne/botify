Einstellungen & API

Wird lokal im Browser gespeichert und ausschließlich für die Musiksuche über die YouTube Data API v3 genutzt.

Kein eigener Server nötig: Die App nutzt automatisch öffentliche Audio-Gateways für Safari-Hintergrundwiedergabe und fällt sonst direkt auf den YouTube-Player zurück.

Hinweis zu Fehler 153 in der Vorschau: YouTube blockiert eingebettete Player innerhalb von Sandbox-Vorschauen (wie Gemini Canvas). Sobald du diese HTML-Datei kostenlos auf GitHub Pages, Netlify oder Vercel hochlädst (statisches Hosting, 0 Wartung), verschwindet Fehler 153 sofort!

iPhone / Safari Tipp: Öffne die gehostete Seite in Safari → Teilen → Zum Home-Bildschirm. Falls Safari beim Sperren pausiert, einfach auf dem Sperrbildschirm auf Play drücken.
